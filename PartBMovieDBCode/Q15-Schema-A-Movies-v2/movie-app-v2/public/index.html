How to demonstrate a conflict
  1. Connect clients A and B to the same database and storage mode. Wait for a completed replication cycle in both.
  2. Tick Work offline in client A, then edit and save a movie there.
  3. Edit the same movie differently in client B and let it synchronize with CouchDB.
  4. Uncheck Work offline in A. After synchronization, the conflict banner appears. Inspect both versions and choose one.
Two edits must start from the same shared revision. Editing only one disconnected copy is not a conflict. In array mode the conflict belongs to the entire parent document.
